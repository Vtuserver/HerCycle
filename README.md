# HerCycle

A menstrual cycle tracking web app built with Next.js, TypeScript, MongoDB/Mongoose and NextAuth.

## Setup
1. Install Node.js 20 LTS or newer.
2. Copy `.env.example` to `.env.local`.
3. Add your MongoDB Atlas connection string and a strong AUTH_SECRET.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open http://localhost:3000.

Do not commit `.env.local`.
